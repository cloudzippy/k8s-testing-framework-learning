# Kubernetes SIG E2E Framework

This directory contains the first learning track.

## Goal

Learn how to design and execute Kubernetes end-to-end tests using the Kubernetes SIG E2E Framework and Go's native testing facilities.

## Planned progression

- Lab 01 — cluster connectivity
- Lab 02 — Kubernetes resource lifecycle
- Lab 03 — workload testing
- Lab 04 — Services and networking
- Lab 05 — Kind-managed test environments
- Later — storage, scheduling, security, resilience, reusable helpers, filtering, and CI

Labs will be added progressively rather than pre-generated.
